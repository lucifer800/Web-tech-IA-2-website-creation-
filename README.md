# Energy Cup '27 — PDEU Inter-University Sports Fest

A React-based website for Energy Cup 2027, the flagship inter-university sports festival hosted by Pandit Deendayal Energy University, Gandhinagar.

## Tech Stack

- **Vite** — fast build tool and dev server
- **React** — component-based UI library
- **React Router** — client-side routing (coming in later commits)
- **CSS Variables** — design tokens for consistent theming

## Getting Started

```bash
npm install
npm run dev
```

## Project Structure

```
src/
├── assets/        # Images and static media
├── components/    # Reusable React components
├── data/          # Content data (sports, fixtures, standings, etc.)
├── hooks/         # Custom React hooks
├── pages/         # Route-level page components
├── styles/        # Global styles and design tokens
├── App.jsx        # Root component
└── main.jsx       # Entry point
```

## Design

Dark-themed sports UI with orange (#ff6a1f) and amber (#ffb21f) accents. Typography uses Big Shoulders Display for headings, Archivo for body text, and IBM Plex Mono for labels.
